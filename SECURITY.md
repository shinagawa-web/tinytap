# Security Policy

## Supported Versions

tinytap is pre-1.0 and under active development. Only the latest release is supported.

| Version | Supported |
| ------- | --------- |
| latest  | Yes       |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub Issues — tinytap runs as root and captures process traffic, so a public issue could expose others before a fix ships.

Instead, use [GitHub Private Vulnerability Reporting](https://github.com/shinagawa-web/tinytap/security/advisories/new) to disclose the issue privately.

Please include the following information:

- A description of the vulnerability
- Steps to reproduce
- Potential impact

We will respond within **7 days** and work with you on a fix and coordinated disclosure.
